# 📝 To-Do List

Um sistema simples de **Lista de Tarefas desenvolvido em Python**, criado como projeto de estudo para praticar lógica de programação e conceitos básicos da linguagem.

## 🚀 Funcionalidades

* ➕ Adicionar tarefas
* 📋 Visualizar tarefas
* ✅ Concluir tarefas
* 🗑️ Remover tarefas
* 🔢 Validação do número da tarefa
* ⚠️ Tratamento de lista vazia
* 🖥️ Limpeza do terminal

## 🛠️ Tecnologias utilizadas

* **Python 3**
* Biblioteca `os`
* Biblioteca `platform`

## 📚 Conceitos praticados

* Variáveis
* Listas
* Estruturas condicionais (`if`, `elif`, `else`)
* Estruturas de repetição (`for` e `while`)
* Funções
* Índices de listas
* `append()` e `pop()`
* Validação de dados
* Importação de bibliotecas
* Interação com o terminal

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/renasrdgs09-cmyk/To-Do-List.git
```

### 2. Entre na pasta

```bash
cd To-Do-List
```

### 3. Execute o programa

```bash
python main.py
```
