# 📝 To-Do List

Um aplicativo simples de lista de tarefas desenvolvido em **Python**, executado pelo terminal.

Este projeto foi desenvolvido como parte dos meus estudos em Python, com o objetivo de praticar conceitos fundamentais da linguagem e lógica de programação.

## 🚀 Funcionalidades

* ➕ Adicionar tarefas
* 📋 Visualizar tarefas
* ✅ Concluir tarefas
* 🗑️ Remover tarefas
* 🔢 Validação do número da tarefa
* ⚠️ Tratamento de lista vazia
* 🖥️ Limpeza automática do terminal para Windows e outros sistemas

## 🛠️ Tecnologias utilizadas

* **Python**
* Biblioteca `os`
* Biblioteca `platform`

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/renasrdgs09-cmyk/to-do-list-python.git
```

### 2. Entre na pasta do projeto

```bash
cd to-do-list-python
```

### 3. Execute o programa

```bash
python main.py
```

## 💻 Como funciona

Ao iniciar o programa, o usuário pode escolher entre cinco opções:

```text
[1] Adicionar Tarefa
[2] Visualizar Tarefas
[3] Concluir Tarefa
[4] Remover Tarefa
[5] Sair
```

As tarefas são armazenadas em uma lista durante a execução do programa.

Exemplo:

```text
1 - Estudar Python
2 - Fazer exercício
3 - Estudar Java
```

Após concluir uma tarefa:

```text
1 - ✅ Estudar Python
2 - Fazer exercício
3 - Estudar Java
```
